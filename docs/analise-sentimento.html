1. Estatística da Polaridade por Obra

A tabela a seguir consolida o comportamento afetivo de cada romance segundo o léxico OpLexicon v3.0, apresentando a proporção de termos positivos, a média e a mediana de saldo emocional por capítulo, a volatilidade dramática (desvio padrão) e os capítulos extremos de cada narrativa. O teste não paramétrico de Kruskal-Wallis (\(\chi^2 = 95.5\), \(p = <2e-16\)) confirma diferenças estatisticamente significativas na distribuição de polaridade entre as obras.

Ver código R 
tabela_sentimentos <- df_sentimento %>%
  group_by(fase, book_short) %>%
  summarise(
    pct_pos = sum(n_positivas) / (sum(n_positivas) + sum(n_negativas)),
    media_cap = mean(polaridade_soma),
    mediana_cap = median(polaridade_soma),
    desvio_cap = sd(polaridade_soma),
    cap_pos = chapter_name[which.max(polaridade_soma)],
    max_val = max(polaridade_soma),
    cap_neg = chapter_name[which.min(polaridade_soma)],
    min_val = min(polaridade_soma),
    .groups = "drop"
  ) %>%
  arrange(desc(media_cap))

tabela_sentimentos %>%
  gt() %>%
  cols_label(
    fase = "Fase Literária",
    book_short = "Obra",
    pct_pos = "% Positivas",
    media_cap = "Média / Cap.",
    mediana_cap = "Mediana / Cap.",
    desvio_cap = "Volatilidade (DP)",
    cap_pos = "Capítulo Mais Positivo",
    max_val = "Saldo Máx.",
    cap_neg = "Capítulo Mais Negativo",
    min_val = "Saldo Mín."
  ) %>%
  fmt_percent(columns = pct_pos, decimals = 1, dec_mark = ",") %>%
  fmt_number(columns = c(media_cap, mediana_cap, desvio_cap), decimals = 2, dec_mark = ",") %>%
  fmt_number(columns = c(max_val, min_val), decimals = 0) %>%
  data_color(columns = media_cap, palette = c("#fee0d2", "#e5f5e0")) %>%
  tab_header(
    title = md("**Indicadores de Polaridade, Proporção Afetiva e Extremos Narrativos**"),
    subtitle = "Cálculo líquido de sentimentos após remoção de ruído funcional (OpLexicon v3.0)"
  )

2.2 Saldo Médio vs. Volatilidade Dramática entre Capítulos

Enquanto o arco longitudinal revela os picos e vales internos de cada história, os gráficos a seguir sintetizam o tom emocional médio (saldo médio por capítulo) e a volatilidade (desvio padrão) de cada obra:

Ver código R 
df_resumo_plot <- df_sentimento %>%
  group_by(book_short) %>%
  summarise(
    `Saldo Médio por Capítulo` = mean(polaridade_soma, na.rm = TRUE),

    .groups = "drop"

  pivot_longer(cols = -book_short, names_to = "Indicador", values_to = "Valor")

3. Polaridade Vocabular: Nuvem X Frequências

A nuvem comparativa e o gráfico de barras divergentes abaixo contrastam os termos positivos (verde) e negativos (laranja) mais recorrentes no conjunto das obras, evidenciando o léxico afetivo característico de Machado de Assis:

Ver código R 
matriz_nuvem_sent <- df_tokens_sent %>%
  filter(polarity != 0) %>%
  mutate(sentimento = ifelse(polarity > 0, "Positivas", "Negativas")) %>%
  count(term, sentimento, sort = TRUE) %>%
  acast(term ~ sentimento, value.var = "n", fill = 0)

par(mar = c(0, 0, 2, 0))
comparison.cloud(
  matriz_nuvem_sent,
  colors = c("#d95f02", "#1b9e77"),
  max.words = 80,
  scale = c(3.8, 0.8),
  title.size = 1.3,
  title.bg.colors = "white",
  random.order = FALSE
)
title(main = "Nuvem Comparativa (OpLexicon v3.0)")
Ver código R 
top_sent_palavras <- df_tokens_sent %>%
  filter(polarity != 0) %>%
  mutate(sentimento = ifelse(polarity > 0, "Positivas (+1)", "Negativas (-1)")) %>%
  count(sentimento, term, sort = TRUE) %>%
  group_by(sentimento) %>%
  slice_max(n, n = 12, with_ties = FALSE) %>%
  ungroup() %>%
  mutate(n_plot = ifelse(sentimento == "Negativas (-1)", -n, n))

ggplot(top_sent_palavras, aes(x = fct_reorder(term, n_plot), y = n_plot, fill = sentimento)) +

4. Similaridade de Cosseno e Agrupamento Hierárquico

Antes de construir o dendrograma, inspecionamos a Matriz de Similaridade de Cosseno (\(\cos \theta\)) calculada sobre as proporções relativas do vocabulário completo de cada obra. Valores próximos de \(1{,}00\) indicam alta convergência de perfil lexical entre os romances:

4.2 Agrupamento Hierárquico

A partir da matriz de dissimilaridade angular (\(D_{\cos} = 1 - \cos \theta\)), aplica-se o algoritmo hierárquico aglomerativo de Ward (ward.D2). O Coeficiente de Correlação Cofenética (\(CCC = 0.879\)) atesta a fidelidade com que a árvore bidimensional preserva as distâncias originais do espaço vetorial:

Ver código R 
par(mar = c(3, 4, 3.5, 2))

  cluster_livros,
  main = "Clusterização Hierárquica dos 7 Livros de Machado de Assis",

  xlab = "", ylab = "Distância Estilística (1 - Cosseno)",
  hang = -1, lwd = 1.6, col = "#08519c"
)
