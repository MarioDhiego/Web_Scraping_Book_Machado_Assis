Análise de Sentimentos

Trajetória emocional longitudinal (OpLexicon v3.0), volatilidade dramática e polaridade vocabular

1. Estatística da Polaridade por Obra

A tabela a seguir — formatada com o pacote gt (IANNONE et al., 2024) — consolida o comportamento afetivo de cada romance segundo o léxico OpLexicon v3.0 (SOUZA et al., 2011; disponibilizado em R via pacote lexiconPT, GONZAGA, 2017), apresentando a proporção de termos positivos, a média e a mediana de saldo emocional por capítulo, a volatilidade dramática (desvio padrão) e os capítulos extremos de cada narrativa. O teste não paramétrico de Kruskal-Wallis (KRUSKAL; WALLIS, 1952; R CORE TEAM, 2026) (\(\chi^2 = 95.5\), \(p = <2e-16\)) confirma diferenças estatisticamente significativas na distribuição de polaridade entre as obras.

Script R 
tabela_sentimentos <- df_sentimento %>%
  group_by(fase, book_short) %>%
  summarise(
    pct_pos = sum(n_positivas) / (sum(n_positivas) + sum(n_negativas)),
    media_cap = mean(polaridade_soma),
    mediana_cap = median(polaridade_soma),
    desvio_cap = sd(polaridade_soma),
    cap_pos = chapter_name[which.max(polaridade_soma)],
    max_val = max(polaridade_soma),
    cap_neg = chapter_name[which.min(polaridade_soma)],
    min_val = min(polaridade_soma),
    .groups = "drop"
  ) %>%
  arrange(desc(media_cap))

tabela_sentimentos %>%
  gt() %>%
  cols_label(
    fase = "Fase Literária",
    book_short = "Obra",
    pct_pos = "% Positivas",
    media_cap = "Média / Cap.",
    mediana_cap = "Mediana / Cap.",
    desvio_cap = "Volatilidade (DP)",
    cap_pos = "Capítulo Mais Positivo",
    max_val = "Saldo Máx.",
    cap_neg = "Capítulo Mais Negativo",
    min_val = "Saldo Mín."
  ) %>%
  fmt_percent(columns = pct_pos, decimals = 1, dec_mark = ",") %>%
  fmt_number(columns = c(media_cap, mediana_cap, desvio_cap), decimals = 2, dec_mark = ",") %>%
  fmt_number(columns = c(max_val, min_val), decimals = 0) %>%
  data_color(columns = media_cap, palette = c("#fee0d2", "#e5f5e0")) %>%
  tab_header(
    title = md("**Indicadores de Polaridade, Proporção Afetiva e Extremos Narrativos**"),
    subtitle = "Cálculo líquido de sentimentos após remoção de ruído funcional (OpLexicon v3.0)"
  )

2. Trajetória Emocional Longitudinal

2.1 Arcos Emocionais ao Longo da Leitura

O gráfico abaixo — produzido com ggplot2 (WICKHAM et al., 2019) — acompanha a evolução capítulo a capítulo do saldo líquido de polaridade de cada romance, normalizado pelo progresso relativo da narrativa (\(0\%\) a \(100\%\)), com curva de tendência suavizada por regressão local não paramétrica LOESS (CLEVELAND, 1979):

Script R 
g_sent1 <- ggplot(df_sentimento, aes(x = posicao_relativa, 
                                     y = polaridade_soma, 
                                     color = book_short)) +
  geom_hline(yintercept = 0, linetype = "dashed", color = "gray40") +
  geom_line(alpha = 0.45) +
  geom_smooth(method = "loess", formula = y ~ x, se = FALSE, linewidth = 1.1) +
  facet_wrap(~ book_short, scales = "free_y", ncol = 4) +
  scale_x_continuous(labels = scales::percent) +
  labs(
    title = "Arco Emocional dos 7 Livros de Machado de Assis",
    subtitle = "Saldo de polaridade por capítulo (OpLexicon v3.0) com curva de tendência",
    x = "Posição Relativa no Livro",
    y = "Saldo de Sentimento"
  ) +
  theme(legend.position = "none", strip.text = element_text(face = "bold", size = 12))
print(g_sent1)

2.2 Saldo Médio vs. Volatilidade Dramática entre Capítulos

Enquanto o arco longitudinal revela os picos e vales internos de cada história, os gráficos a seguir sintetizam o tom emocional médio (saldo médio por capítulo) e a volatilidade (desvio padrão) de cada obra:

Script R 
df_resumo_plot <- df_sentimento %>%
  group_by(book_short) %>%
  summarise(
    `Saldo Médio por Capítulo` = mean(polaridade_soma, na.rm = TRUE),
    `Volatilidade (Desvio Padrão)` = sd(polaridade_soma, na.rm = TRUE),
    .groups = "drop"
  ) %>%
  pivot_longer(cols = -book_short, names_to = "Indicador", values_to = "Valor")

ggplot(df_resumo_plot, aes(x = reorder_within(book_short, Valor, Indicador), y = Valor, fill = Indicador)) +
  geom_hline(yintercept = 0, color = "gray60", linewidth = 0.4) +
  geom_col(show.legend = FALSE, width = 0.65) +
  geom_text(
    aes(label = round(Valor, 2), hjust = ifelse(Valor >= 0, -0.15, 1.15)),
    size = 3.5
  ) +
  facet_wrap(~ Indicador, scales = "free") +
  coord_flip() +
  scale_x_reordered() +
  scale_y_continuous(expand = expansion(mult = c(0.18, 0.22))) +
  scale_fill_manual(values = c("Saldo Médio por Capítulo" = "#1b9e77", "Volatilidade (Desvio Padrão)" = "#7570b3")) +
  labs(
    title = "Balanço Afetivo e Instabilidade Emocional por Obra",
    subtitle = "Média e dispersão da polaridade líquida entre os capítulos (OpLexicon v3.0)",
    x = NULL,
    y = "Pontuação"
  )

3. Polaridade: Nuvem Comparativa vs. Frequências

A nuvem comparativa — gerada pelos pacotes wordcloud (FELLOWS, 2018) e reshape2 (WICKHAM, 2007) — e o gráfico de barras divergentes — estruturado com tidytext (SILGE; ROBINSON, 2016, 2017) — contrastam os termos positivos (verde) e negativos (laranja) mais recorrentes no conjunto das obras, evidenciando o léxico afetivo característico de Machado de Assis:

Script R 
matriz_nuvem_sent <- df_tokens_sent %>%
  filter(polarity != 0) %>%
  mutate(sentimento = ifelse(polarity > 0, "Positivas", "Negativas")) %>%
  count(term, sentimento, sort = TRUE) %>%
  acast(term ~ sentimento, value.var = "n", fill = 0)

par(mar = c(0, 0, 2, 0))
comparison.cloud(
  matriz_nuvem_sent,
  colors = c("#D55E00", "#0072B2"),
  max.words = 80,
  scale = c(3.8, 0.8),
  title.size = 1.3,
  title.bg.colors = "white",
  random.order = FALSE
)
title(main = "Nuvem Comparativa (OpLexicon v3.0)")
Script R 
top_sent_palavras <- df_tokens_sent %>%
  filter(polarity != 0) %>%
  mutate(sentimento = ifelse(polarity > 0, "Positivas (+1)", "Negativas (-1)")) %>%
  count(sentimento, term, sort = TRUE) %>%
  group_by(sentimento) %>%
  slice_max(n, n = 12, with_ties = FALSE) %>%
  ungroup() %>%
  mutate(n_plot = ifelse(sentimento == "Negativas (-1)", -n, n))

ggplot(top_sent_palavras, aes(x = fct_reorder(term, n_plot), y = n_plot, fill = sentimento)) +
  geom_col(width = 0.72) +
  geom_text(
    aes(label = abs(n_plot), hjust = ifelse(n_plot >= 0, -0.15, 1.15)),
    size = 3.1
  ) +
  coord_flip() +
  scale_y_continuous(labels = abs, expand = expansion(mult = c(0.18, 0.18))) +
  scale_fill_manual(values = c("Negativas (-1)" = "#D55E00", "Positivas (+1)" = "#0072B2")) +
  labs(
    title = "Principais Termos por Polaridade",
    x = NULL, y = "Frequência Absoluta", fill = NULL
  ) +
  theme(legend.position = "bottom")

Síntese Interpretativa e Nota Bibliográfica: Embora romances como Helena e Memorial de Aires apresentem saldos médios mais elevados devido à polidez social e cortesia dos diálogos, a curva LOESS (CLEVELAND, 1979) revela a queda sistemática da polaridade no terço final das narrativas realistas (Dom Casmurro, Quincas Borba e Memórias Póstumas), refletindo a desilusão psicológica, o ciúme e a degradação trágica dos protagonistas.
