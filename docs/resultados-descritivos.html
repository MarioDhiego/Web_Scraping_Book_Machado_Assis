Volumetria, complexidade vocabular, assinatura temática (TF-IDF) e dispersão narrativa

Visão Geral do Corpus: O conjunto analisado reúne 7 obras integrais de Machado de Assis (6 romances e 1 novela) (ASSIS, 1876, 1881, 1882, 1891, 1899, 1904, 1908), totalizando 827 capítulos, 8.915 parágrafos e mais de 428 mil tokens extraídos diretamente do Wikisource em português (FUNDAÇÃO WIKIMEDIA, 2026) e processados via tidyverse (WICKHAM et al., 2019) e quanteda (BENOIT et al., 2018).

1. Estatística Descritiva das Obras

A tabela executiva abaixo — formatada com o pacote gt (IANNONE et al., 2024) — consolida a estrutura narrativa de cada obra, agrupada por escola/fase literária (CANDIDO, 1970; BOSI, 1994), detalhando a quantidade de capítulos, parágrafos, volume total de palavras (tokens) e as médias de extensão por unidade estrutural.

Script R 
tabela_geral <- df_livros %>%
  mutate(tokens_brutos = str_count(text, "\\S+")) %>%
  group_by(fase, book_short) %>%
  summarise(
    capitulos = n_distinct(chapter_name),
    paragrafos = n(),
    total_tokens = sum(tokens_brutos),
    media_palavras_cap = round(total_tokens / capitulos, 1),
    media_palavras_par = round(total_tokens / paragrafos, 1),
    .groups = "drop"
  ) %>%
  arrange(fase, desc(total_tokens))

tabela_geral %>%
  gt(groupname_col = "fase") %>%
  cols_label(
    book_short = "Obra",
    capitulos = "Capítulos",
    paragrafos = "Parágrafos",
    total_tokens = "Tokens",
    media_palavras_cap = "Tokens/Cap.",
    media_palavras_par = "Tokens/Par."
  ) %>%
  fmt_number(columns = c(capitulos, paragrafos, total_tokens), decimals = 0, sep_mark = ".") %>%
  fmt_number(columns = c(media_palavras_cap, media_palavras_par), decimals = 1, dec_mark = ",") %>%
  summary_rows(
    columns = c(capitulos, paragrafos, total_tokens),
    fns = list(Subtotal = ~ sum(.)),
    fmt = ~ fmt_number(., decimals = 0, sep_mark = ".")
  ) %>%
  grand_summary_rows(
    columns = c(capitulos, paragrafos, total_tokens),
    fns = list(`Total Geral` = ~ sum(.)),
    fmt = ~ fmt_number(., decimals = 0, sep_mark = ".")
  ) %>%
  tab_header(
    title = md("**Volumetria e Arquitetura Narrativa das Obras**"),
    subtitle = "Comparação estrutural entre a Fase Romântica e a Fase Realista"
  ) %>%
  tab_source_note("Fonte: Elaboração própria a partir de textos integrais do Wikisource.")

Consulta Interativa por Capítulo (DT)

Para inspecionar a granularidade interna de cada romance, a tabela dinâmica abaixo — construída com o pacote DT (XIE; CHENG; TAN, 2024) — permite pesquisar, ordenar e filtrar todos os 827 capítulos por obra, número de parágrafos e extensão em palavras:

Script R 
df_capitulos_dt <- df_livros %>%
  mutate(tokens_brutos = str_count(text, "\\S+")) %>%
  group_by(Obra = book_short, Fase = fase, Capítulo = chapter_name) %>%
  summarise(
    Parágrafos = n(),
    Tokens = sum(tokens_brutos),
    `Média Tokens/Par.` = round(Tokens / Parágrafos, 1),

2. Complexidade Léxica e Legibilidade

A segunda tabela avalia a riqueza do repertório vocabular de cada livro por meio do pacote quanteda.textstats (BENOIT et al., 2018) após a higienização de pontuação e stopwords, contrastando o índice bruto (TTR) com o índice corrigido pela extensão (CTTR) (CARROLL, 1964) e a complexidade sintática (Flesch-Kincaid) (KINCAID et al., 1975).

Script R 
div_lexica <- textstat_lexdiv(matriz_dfm, measure = c("TTR", "CTTR"))
legibilidade <- textstat_readability(meu_corpus, measure = "Flesch.Kincaid")

tabela_complexidade <- div_lexica %>%
  left_join(legibilidade, by = "document") %>%
  left_join(
    tibble(
      document = docnames(matriz_dfm),
      vocab_unico = ntype(matriz_dfm),
      tokens_uteis = ntoken(matriz_dfm)
    ),
    by = "document"
  ) %>%
  select(
    Livro = document,
    vocab_unico,
    tokens_uteis,
    Diversidade_TTR = TTR,
    Diversidade_Corrigida_CTTR = CTTR,
    Complexidade_Flesch_Kincaid = Flesch.Kincaid
  ) %>%
  arrange(desc(Diversidade_Corrigida_CTTR))

tabela_complexidade %>%
  gt() %>%
  cols_label(
    Livro = "Obra",
    vocab_unico = "Vocabulário Único (Types)",
    tokens_uteis = "Tokens Úteis",
    Diversidade_TTR = "TTR (Bruto)",
    Diversidade_Corrigida_CTTR = "CTTR (Corrigido)",
    Complexidade_Flesch_Kincaid = "Flesch-Kincaid"
  ) %>%
  fmt_number(columns = c(vocab_unico, tokens_uteis), decimals = 0, sep_mark = ".") %>%
  fmt_number(columns = c(Diversidade_TTR, Diversidade_Corrigida_CTTR, Complexidade_Flesch_Kincaid), decimals = 3, dec_mark = ",") %>%
  data_color(columns = Diversidade_Corrigida_CTTR, palette = c("#f7fbff", "#2171b5")) %>%
  tab_header(
    title = md("**Riqueza Vocabular e Legibilidade Sintática**"),
    subtitle = "Ordenado pela diversidade léxica corrigida (CTTR)"
  )

3. Frequência Vocabular e Assinatura Temática (TF-IDF)

3.1 Termos Mais Frequentes por Obra

Utilizando a abordagem tidy de tokenização do pacote tidytext (SILGE; ROBINSON, 2016, 2017), exibem-se os 15 vocábulos mais recorrentes em cada narrativa:

Script R 
top_palavras <- df_livros %>%
  unnest_tokens(word, text) %>%
  filter(!word %in% c(stopwords("portuguese"), sw_extra), 
         !str_detect(word, "^[0-9]+$"),
         nchar(word) > 2) %>%
  count(book_short, word, sort = TRUE) %>%
  group_by(book_short) %>%
  slice_max(n, n = 15, with_ties = FALSE) %>%
  ungroup()

ggplot(top_palavras, aes(x = reorder_within(word, n, book_short), y = n, fill = book_short)) +
  geom_col(show.legend = FALSE) +
  facet_wrap(~ book_short, scales = "free", ncol = 4) +
  coord_flip() +
  scale_x_reordered() +
  labs(
    title = "Top 15 Palavras Mais Frequentes por Livro",
    subtitle = "Frequência absoluta após remoção de stopwords e verbos auxiliares",
    x = NULL, y = "Frequência Absoluta"
  ) +
  theme(strip.text = element_text(face = "bold", size = 12))

3.2 Assinatura Vocabular Distintiva (TF-IDF)

Enquanto a frequência bruta destaca vocábulos comuns a todo o corpus, a ponderação TF-IDF (SPÄRCK JONES, 1972; SALTON; MCGILL, 1983; SILGE; ROBINSON, 2017) isola os termos exclusivos que caracterizam o universo de cada romance:

Script R 
tfidf_livros <- df_livros %>%
  unnest_tokens(word, text) %>%
  filter(!word %in% c(stopwords("portuguese"), sw_extra),
         !str_detect(word, "^[0-9]+$"),
         nchar(word) > 2) %>%
  count(book_short, word, sort = TRUE) %>%
  bind_tf_idf(word, book_short, n) %>%
  group_by(book_short) %>%
  slice_max(tf_idf, n = 10, with_ties = FALSE) %>%
  ungroup()

ggplot(tfidf_livros, aes(x = reorder_within(word, tf_idf, book_short), y = tf_idf, fill = book_short)) +
  geom_col(show.legend = FALSE) +
  facet_wrap(~ book_short, scales = "free", ncol = 4) +
  coord_flip() +
  scale_x_reordered() +
  labs(
    title = "Assinatura Vocabular Exclusiva de Cada Obra (TF-IDF)",
    subtitle = "Termos com maior poder de discriminação temática entre os 7 livros",
    x = NULL, y = "Pontuação TF-IDF"
  ) +
  theme(strip.text = element_text(face = "bold", size = 12))

4.2 Dispersão Léxica ao Longo das Narrativas (Gráfico de Raio-X)

Utilizando a concordância Keyword-in-Context (kwic) e a visualização textplot_xray() do pacote quanteda.textplots (BENOIT et al., 2018), rastreia-se a posição exata de termos estruturantes do início ao desfecho de cada livro:

Script R 
kwic_busca <- kwic(
  tokens(meu_corpus),
  pattern = c("olhos", "alma", "amor", "dinheiro", "senhora"),
  case_insensitive = TRUE
)

kwic_busca$docname <- factor(kwic_busca$docname, levels = docnames(meu_corpus))

textplot_xray(kwic_busca, scale = "relative") +
  aes(color = keyword) +
  scale_color_brewer(palette = "Dark2", guide = "none") +
  facet_grid(docname ~ keyword, drop = FALSE) +
  labs(
    title = "Dispersão Léxica ao Longo dos 7 Livros (Raio-X)",

Síntese Interpretativa e Nota Bibliográfica: Os resultados descritivos demonstram a eficácia da correção de escala: enquanto O Alienista lidera o TTR bruto por ser uma novela curta, os grandes romances realistas (Quincas Borba e Memórias Póstumas) assumem a liderança no CTTR devido à amplitude de seu repertório vocabular. No plano temático, o TF-IDF recupera com precisão os núcleos narrativos de cada obra (Capitu/Escobar em Dom Casmurro; Rubião/Sofia em Quincas Borba; Bacamarte/Itaguaí em O Alienista), enquanto o mapa de calor comprova a concentração máxima do motivo “olhos” em Dom Casmurro e da dicotomia “razão/loucura” em O Alienista.       str_detect(book_name, "Helena") ~ "Helena",
```{r}
      str_detect(book_name, "Memorial de Aires") ~ "Memorial de Aires",
      str_detect(book_name, "Esaú") ~ "Esaú e Jacó",
      TRUE ~ book_name
    ),
    fase = ifelse(book_short == "Helena", "Fase Romântica", "Fase Realista")
  )

# Agregação para Corpus e DFM
df_corpus_agregado <- df_livros %>%
  group_by(book_short) %>%
  summarise(text = paste(text, collapse = " "), .groups = "drop")

meu_corpus <- corpus(df_corpus_agregado$text, docnames = df_corpus_agregado$book_short)

sw_extra <- c("é", "era", "disse", "ia", "ser", "ter", "havia", "ainda", 
              "assim", "tudo", "nada", "outro", "outra", "dous", "cousa")

tokens_limpos <- tokens(
  meu_corpus,
  remove_punct = TRUE,
  remove_numbers = TRUE,
  remove_symbols = TRUE
) %>%
  tokens_tolower() %>%
  tokens_remove(c(stopwords("portuguese"), sw_extra))

matriz_dfm <- dfm(tokens_limpos)
```

## 3. Frequência Vocabular e Assinatura Temática (TF-IDF)
### 3.1 Termos Mais Frequentes por Obra

Utilizando a abordagem tidy de tokenização do pacote tidytext (SILGE; ROBINSON, 2016, 2017), exibem-se os 15 vocábulos mais recorrentes em cada narrativa:


```{r}
#| label: fig-top-palavras
#| fig-cap: "Top 15 palavras mais frequentes em cada obra (excluindo stopwords)."
#| fig-width: 12
#| fig-height: 7.5

top_palavras <- df_livros %>%
  unnest_tokens(word, text) %>%

  group_by(book_short) %>%
```

### 3.2 Assinatura Vocabular Distintiva (TF-IDF)

Enquanto a frequência bruta destaca vocábulos comuns a todo o corpus, a ponderação TF-IDF (SPÄRCK JONES, 1972; SALTON; MCGILL, 1983; SILGE; ROBINSON, 2017) isola os termos exclusivos que caracterizam o universo de cada romance:



```{r}
#| label: fig-tfidf
#| fig-cap: "Top 10 termos mais exclusivos de cada obra segundo a métrica TF-IDF (SPÄRCK JONES, 1972)."
#| fig-width: 12
#| fig-height: 6.5

tfidf_livros <- df_livros %>%
  unnest_tokens(word, text) %>%
  filter(!word %in% c(stopwords("portuguese"), sw_extra),
         !str_detect(word, "^[0-9]+$"),
         nchar(word) > 2) %>%
  count(book_short, word, sort = TRUE) %>%
  bind_tf_idf(word, book_short, n) %>%
  group_by(book_short) %>%
  slice_max(tf_idf, n = 10, with_ties = FALSE) %>%
  ungroup()

ggplot(tfidf_livros, aes(x = reorder_within(word, tf_idf, book_short), y = tf_idf, fill = book_short)) +
  geom_col(show.legend = FALSE) +
  facet_wrap(~ book_short, scales = "free", ncol = 4) +
  coord_flip() +
  scale_x_reordered() +
  labs(
    title = "Assinatura Vocabular Exclusiva de Cada Obra (TF-IDF)",
    subtitle = "Termos com maior poder de discriminação temática entre os 7 livros",
    x = NULL, y = "Pontuação TF-IDF"
  ) +
  theme(strip.text = element_text(face = "bold", size = 12))

```

### 4.2 Dispersão Léxica ao Longo das Narrativas (Gráfico de Raio-X)

Utilizando a concordância Keyword-in-Context (kwic) e a visualização textplot_xray() do pacote quanteda.textplots (BENOIT et al., 2018), rastreia-se a posição exata de termos estruturantes do início ao desfecho de cada livro:


```{r}
#| label: fig-xray

#| fig-width: 11
#| fig-height: 6.5

kwic_busca <- kwic(
  tokens(meu_corpus),
  pattern = c("olhos", "alma", "amor", "dinheiro", "senhora"),
```

```{r}
#| label: fig-bigramas
```

Síntese Interpretativa e Nota Bibliográfica: Os resultados descritivos demonstram a eficácia da correção de escala: enquanto O Alienista lidera o TTR bruto por ser uma novela curta, os grandes romances realistas (Quincas Borba e Memórias Póstumas) assumem a liderança no CTTR devido à amplitude de seu repertório vocabular. No plano temático, o TF-IDF recupera com precisão os núcleos narrativos de cada obra (Capitu/Escobar em Dom Casmurro; Rubião/Sofia em Quincas Borba; Bacamarte/Itaguaí em O Alienista), enquanto o mapa de calor comprova a concentração máxima do motivo "olhos" em Dom Casmurro e da dicotomia "razão/loucura" em O Alienista.
