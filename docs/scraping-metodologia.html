2. Estratégia de Web Scraping (pt.wikisource.org)

O Wikisource (FUNDAÇÃO WIKIMEDIA, 2026) é uma biblioteca digital livre mantida pela Fundação Wikimedia que hospeda obras em domínio público fielmente transcritas. Diferente de repositórios com arquivos únicos em .txt, os romances de Machado de Assis no Wikisource em português são organizados hierarquicamente na árvore DOM/HTML (MITCHELL, 2018):

  1. Página Índice da Obra: Contém os metadados bibliográficos e uma lista de hiperlinks apontando para cada capítulo individual (ex.: /wiki/Dom_Casmurro/I, /wiki/Dom_Casmurro/II).
  2. Subpáginas de Capítulos: Contêm o texto literário propriamente dito, encapsulado dentro do seletor HTML #mw-content-text .mw-parser-output p, acompanhado de elementos de navegação (Anterior, Próximo, Índice) e notas de rodapé numéricas ([1], [2]).

Contorno de Proxy e Leitura Nativa (wininet)

Em ambientes Windows corporativos ou institucionais com restrições de proxy, requisições diretas via curl ou httr frequentemente sofrem bloqueio de certificado SSL ou timeout. Para garantir estabilidade, implementou-se uma função de leitura baseada no motor nativo de rede do Windows (method = "wininet" via download.file), combinada com detecção automática de proxy via curl::ie_get_proxy_for_url() (OOMS, 2024) e três boas práticas de raspagem ética (MITCHELL, 2018):

  • Pausa ética (Sys.sleep(0.25)): Intervalo de 250 milissegundos entre requisições para não sobrecarregar os servidores da Wikimedia.
  • Decodificação de URLs (URLdecode): Normalização de caracteres acentuados (como em Memórias Póstumas e Esaú e Jacó) para garantir o pareamento exato dos links de capítulos.
  • Persistência em Cache (.rds): Armazenamento local da base bruta após a primeira coleta, garantindo reprodutibilidade offline.
Script R 
library(tidyverse)
library(rvest)

# Configuração automática de proxy do sistema Windows (protegida contra NULL/vazio)
proxy_sistema <- tryCatch(
  curl::ie_get_proxy_for_url("[https://pt.wikisource.org](https://pt.wikisource.org)"),
  error = function(e) NULL
)

if (length(proxy_sistema) > 0 && !is.na(proxy_sistema[1]) && nzchar(proxy_sistema[1])) {
  Sys.setenv(https_proxy = proxy_sistema[1], http_proxy = proxy_sistema[1])
}

# Função de leitura HTML usando motor nativo wininet
ler_html_wininet <- function(url) {
  arquivo_temp <- tempfile(fileext = ".html")
  status <- tryCatch(
    suppressWarnings(download.file(url, destfile = arquivo_temp, method = "wininet", quiet = TRUE)),
    error = function(e) return(1)
  )
  if (status != 0 || !file.exists(arquivo_temp)) return(NULL)
  pagina <- tryCatch(read_html(arquivo_temp, encoding = "UTF-8"), error = function(e) NULL)
  unlink(arquivo_temp)
  return(pagina)
}

# Extração dos parágrafos de cada capítulo
extrair_texto_pagina <- function(url_pagina) {
  Sys.sleep(0.25) # Pausa ética
  pagina <- ler_html_wininet(url_pagina)
  if (is.null(pagina)) return(tibble(url = url_pagina, paragraph_number = NA_integer_, text = NA_character_))
  
  paragrafos <- pagina %>%
    html_elements("#mw-content-text .mw-parser-output p") %>%
    html_text2() %>%
    str_remove_all("\\[\\d+\\]") %>% # Remove referências de notas de rodapé
    str_squish()
  
  paragrafos <- paragrafos[paragrafos != "" & nchar(paragrafos) > 1]
  tibble(url = url_pagina, paragraph_number = seq_along(paragrafos), text = paragrafos)
}

# Navegação na página índice da obra e coleta sequencial dos capítulos
extrair_livro_wikisource <- function(url_livro) {
  pagina_indice <- ler_html_wininet(url_livro)
  if (is.null(pagina_indice)) return(tibble())
  
  titulo_livro <- pagina_indice %>%
    html_element("#firstHeading") %>%
    html_text2() %>%
    str_squish()
  
  prefixo_obra <- str_remove(URLdecode(url_livro), "^https://pt\\.wikisource\\.org")
  
  links_caps <- pagina_indice %>%
    html_elements("#mw-content-text .mw-parser-output a") %>%
    html_attr("href") %>%
    discard(is.na) %>%
    URLdecode() %>%
    keep(~ str_starts(.x, paste0(prefixo_obra, "/"))) %>%
    str_remove("#.*$") %>%
    unique()
  
  urls_caps <- paste0("[https://pt.wikisource.org](https://pt.wikisource.org)", links_caps)
  
  map_dfr(urls_caps, function(u) {
    extrair_texto_pagina(u) %>%
      mutate(
        book_name = titulo_livro,
        chapter_name = str_remove(URLdecode(u), "^.*/"),
        .before = 1
      )
  })
}

3. Limpeza, Padronização e Estruturação do Banco de Dados

Os textos brutos extraídos da web contêm ruídos estruturais que precisam ser removidos antes de qualquer cálculo estatístico (SILGE; ROBINSON, 2017). O fluxo de higienização segue quatro etapas:

  1. Filtragem de Ruído Editorial: Remoção de linhas vazias (NA) e de parágrafos administrativos capturados acidentalmente pelos seletores HTML (como cabeçalhos iniciados por “Índice”, “Anterior”, “Próximo”, “Wikisource” ou “Obra editada”).
  2. Padronização de Metadados: Criação de identificadores curtos (book_short) para visualização gráfica e classificação das obras segundo a periodização crítica da literatura brasileira (Fase Romântica vs. Fase Realista) (CANDIDO, 1970; BOSI, 1994).
  3. Estruturação Tabular (Tidy Data): Organização do banco em quatro variáveis fundamentais segundo os princípios de dados arrumados de Wickham (2014): book_short (obra), chapter_name (capítulo), paragraph_number (ordem sequencial do parágrafo) e text (conteúdo textual limpo).
  4. Remoção de Stopwords e Arcaísmos: Para a análise de frequência e modelagem temática, eliminam-se pontuações, algarismos, símbolos, stopwords padrão da língua portuguesa e termos auxiliares/arcaicos recorrentes na prosa oitocentista (como “dous”, “cousa”, “havia”, “disse”), construindo a Matriz Documento-Termo (dfm) no pacote quanteda (BENOIT et al., 2018).
Script R 
library(tidyverse)
library(quanteda)

# Higienização e enriquecimento de metadados
df_livros <- df_livros_bruto %>%
  filter(!is.na(text)) %>%
  filter(!str_detect(text, "^(Índice|Anterior|Próximo|Wikisource|Obra editada)")) %>%
  mutate(
    author = "Machado de Assis",
    book_short = case_when(
      str_detect(book_name, "Dom Casmurro") ~ "Dom Casmurro",
      str_detect(book_name, "Brás Cubas") ~ "Memórias Póstumas",
      str_detect(book_name, "Quincas Borba") ~ "Quincas Borba",
      str_detect(book_name, "Alienista") ~ "O Alienista",
      str_detect(book_name, "Helena") ~ "Helena",
      str_detect(book_name, "Memorial de Aires") ~ "Memorial de Aires",
      str_detect(book_name, "Esaú") ~ "Esaú e Jacó",
      TRUE ~ book_name
    ),
    fase = ifelse(book_short == "Helena", "Fase Romântica", "Fase Realista")
  )

# Agregação por obra para construção do Corpus e da Matriz Documento-Termo (DFM)
df_corpus_agregado <- df_livros %>%
  group_by(book_short) %>%
  summarise(text = paste(text, collapse = " "), .groups = "drop")

meu_corpus <- corpus(df_corpus_agregado$text, docnames = df_corpus_agregado$book_short)

sw_extra <- c("é", "era", "disse", "ia", "ser", "ter", "havia", "ainda", 
              "assim", "tudo", "nada", "outro", "outra", "dous", "cousa")

tokens_limpos <- tokens(
  meu_corpus,
  remove_punct = TRUE,
  remove_numbers = TRUE,
  remove_symbols = TRUE
) %>%
  tokens_tolower() %>%
  tokens_remove(c(stopwords("portuguese"), sw_extra))

matriz_dfm <- dfm(tokens_limpos)

4. Fluxo Completo da Arquitetura

O fluxograma e o quadro abaixo resumem a transformação dos dados desde o código-fonte HTML até os modelos analíticos apresentados nas próximas abas:

Estágio Entrada Processamento Saída Estruturada
1. Coleta URLs do Wikisource (HTML) Raspagem DOM via rvest + wininet (WICKHAM, 2024) Arquivo local .rds bruto
2. Higienização Parágrafos brutos com ruído Regex (stringr) + filtros de metadados (WICKHAM, 2014) Tabela df_livros (827 capítulos)
3. Tokenização Texto corrido por obra Normalização + remoção de stopwords (BENOIT et al., 2018) corpus e dfm (quanteda)
4. Modelagem dfm + OpLexicon v3.0 Estatística léxica, TF-IDF, sentimentos e clusters (SILGE; ROBINSON, 2017) Tabelas gt e gráficos ggplot2
